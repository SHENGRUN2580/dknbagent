# 岗位任务转教学任务智能体 - 技术部署文档## 1. 项目概述### 1.1 项目简介本项目是一个基于 **LangGraph** 和 **LangChain** 构建的智能教学任务生成系统，能够将企业真实工作任务自动转化为可用于教学的学习型工作任务，实现"以岗定教"的产教融合目标。### 1.2 核心功能| 功能模块 | 功能描述 ||---------|---------|| 任务解析 | 自动识别任务类型，匹配目标岗位和专业 || 知识点提取 | 根据任务和岗位匹配相关理论知识 || 技能点提取 | 匹配所需操作技能和熟练度要求 || 步骤生成 | 生成详细的分步操作指南 || 安全汇总 | 汇总所有安全要点 || 资源匹配 | 关联微课、仿真软件等实训资源 |### 1.3 技术亮点- **多模型支持**：支持 DeepSeek、OpenAI 等多种 LLM 模型- **降级机制**：无 API 环境下自动切换本地规则匹配- **灵活配置**：支持环境变量和配置文件两种配置方式---## 2. 技术栈| 分类 | 技术 | 版本要求 ||------|------|---------|| 语言 | Python | >= 3.10 || 框架 | Key（临时生效）$env:DEEPSEEK_API_KEY="your-deepseek-api-key"# 设置系统环境变量（永久生效）[Environment]::SetEnvironmentVariable("DEEPSEEK_API_KEY", "your-deepseek-api-key", "User")```**Linux/Mac：**```bash# 方式二：.env 文件配置编辑 `.env` 文件：```env# DeepSeek配置DEEPSEEK_API_KEY=your-deepseek-api-keyDEEPSEEK_API_BASE=https://api.deepseek.com/v1# `https://api.openai.com/v1` | `gpt-3.5-turbo` |### 6.3 可选配置| 配置项 | 说明 | 默认值 ||--------|------|-------|| `LANGCHAIN_TRACING_V2` | 是否启用 LangChain 追踪 | `false` || `LANGCHAIN_API_KEY` | LangChain API Key | 空 || `CHROMA_DB_PATH` | Chroma 数据库路径 | `./chromadb` |---## 7. 项目结构```ai agent/├── .env                    # 环境变量配置├── requirement.txt         # 依赖列表├── langgraph.json          #
